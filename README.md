# Roamly — Personalized Travel Itinerary Planner

A responsive, beginner-friendly travel planning web app. Enter a destination, trip length, budget, interests, and travel pace to generate a suggested day-by-day itinerary with an estimated budget.

## Features

- Responsive layout for desktop, tablet, and mobile
- Itinerary generation for 1–7 days
- Interest selection: culture, food, nature, adventure, relaxation, shopping
- Three travel paces: relaxed, balanced, packed
- Budget estimate per person in Indian rupees
- Save a plan to browser local storage
- Print the itinerary or choose “Save as PDF” in the print dialog
- No sign-up, backend, or API key required

## Run locally

**Option 1 — simplest**
1. Extract the ZIP file.
2. Open the `personalized-travel-itinerary-planner` folder.
3. Double-click `index.html` to open it in your browser.

**Option 2 — Visual Studio Code**
1. Open the extracted folder in VS Code.
2. Install the **Live Server** extension (optional).
3. Right-click `index.html` and select **Open with Live Server**.

The project uses plain HTML, CSS, and JavaScript. An internet connection is used for Google Fonts and the decorative Unsplash photos; the planner itself works without an API key.

## Deploy online for free

### GitHub Pages
1. Create a GitHub repository, for example `roamly-travel-planner`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Open the URL shown in Settings → Pages.

### Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the extracted project folder into the drop area.
4. Netlify will publish the site and provide a public URL.

## Important notes

- This is a functional demo and starting-point itinerary generator, not a live travel booking service.
- The suggestions use built-in rules and generic activity descriptions. They are **not generated by a live AI model** and are not verified against real-time opening hours, transport, weather, or availability.
- Budget numbers are rough illustrative estimates in INR, not quotes.
- Before a real trip, confirm attraction names, opening times, ticket prices, local safety advice, and transport options.
- Saved plans remain in the current browser and are not synced between devices.
- The decorative photos and Google Fonts are remote resources. Replace them with locally hosted assets if you need the entire page to work fully offline.
